# Developing applications for Watchdog Series devices

## Aim

This document provides a guide for developers looking to create applications for the Watchdog Series devices, including the Watchdog 2040, 2350 and future versions in the years to come. It covers the necessary tools, libraries, and best practices for development.

## Prerequisites

Before you start developing applications for Watchdog Series devices, ensure you have the following prerequisites:

- A computer that is capable of booting up, with any operating system created by humans after 2000 CE
